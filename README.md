# ClearBilling · Clinician Mobile Intake (Demo)

**Synthetic data only. Not for clinical use.**

Clinicians log after-case details on mobile for **rapid intake into the ClearBilling portal and billing path**. Packets then move into [Command Center](https://github.com/brivera2005/command-center-demo) for medical coding review, operator signoff, and PM/EHR posting.

## Open the demo

Open [`index.html`](./index.html) locally, or use GitHub Pages once enabled:

**https://brivera2005.github.io/clinician-mobile-intake/**

## Path

1. **Mobile capture** - laterality, CPT, ASA/units, clinician notes  
2. **Portal intake** - rapid handoff into ClearBilling  
3. **Command Center** - coding review + signoff  
4. **PM / EHR** - SOAP/REST CreatePatient / CreateEncounter with fail-safe Draft/Approved sync
