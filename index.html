What Prism looks like

Each step, then the screen. Synthetic data, not a live example. Same taps on a phone or clicks on a computer.

1. Sign in - invited work email + login code. Sessions last 8 hours.

2. How do you want to work today? - tap Add cases (new, recommended) or Upload PDF (classic paper packet). Optional: remember as your default next login.

3. Add cases - MRN, DOS, Times, facility, surgeon, procedure (Cataract, iStent, UL, LL, or Add procedure), diagnosis (Glaucoma, or Add DX), additional notes last. Demographics can follow later and match by MRN.

4. Upload PDF - charge sheets plus demographic sheets for the whole day, week, or whatever you have. One PDF or several. Either is fine. Through Prism instead of email.

How intake works

Two provider workflows. Both stay inside Prism’s gated channel.

1 · Access

Cloudflare Access allowlists the practice email. A single-use login code is emailed. Uninvited addresses never reach the app.

2 · PHI screen

Providers accept a PHI security acknowledgment before working. Activity is logged for ops review.

3 · Capture

Add cases through the day, or Upload PDF for charge sheets plus demographic sheets (day, week, one file or several).

4 · Match by MRN

Demographics can arrive later. Sheets with patient-sticker MRNs sync to open cases for that DOS.

Privacy & security (live product posture)

HIPAA does not "certify" apps. What matters is a real program (BAAs, policies, workforce training) plus live technical safeguards. Prism is the practice-to-Clear Billing transfer channel inside that program.

ControlWhat Prism / Clear Billing runs
Edge Zero Trust Cloudflare Access in front of Prism. Uninvited visitors never reach the app UI.
Allowlisted identity Practice emails must be invited before a login code is issued. No shared office password. Offboarding removes the email.
Time-boxed sessions Access sessions last 8 hours, then a fresh code is required. Out clears the Access session.
Encrypted transport HTTPS with HSTS. Cloudflare Tunnel ingress. App not port-forwarded on the public internet or left open on an office LAN.
Browser hardening Security headers (frame deny, nosniff, referrer policy, content-security posture).
Practice separation Each practice only sees its own cases and uploads.
PHI hygiene Cases/PDFs go to Prism’s vault. Confirmation emails carry no PHI. Charts are not offered as downloads to personal devices.
Audit & backups Sign-in and intake activity logged. Routine backups on Clear Billing’s dedicated host path.
